CAPPADOCIAGO ADMIN LOGIN FIX

Duzeltilenler:
1. /admin/ sayfasindaki admin TypeScript dosyasi artik /src/... public yolu yerine Astro tarafindan bundle edilecek relative yol ile yukleniyor.
2. /admin/tours artik mevcut session yoksa dogrudan kendi login formunu gosteriyor.
3. Supabase environment variables eksikse panel net hata mesaji gosteriyor.
4. Kullanici admin_users tablosunda yetkili degilse net hata mesaji gosteriyor.

Admin yetkilendirme gerekiyorsa Supabase SQL Editor'da Auth > Users icindeki kullanicinin UUID'sini kullanarak:

insert into public.admin_users (user_id, role)
values ('BURAYA_AUTH_USER_UUID', 'admin')
on conflict (user_id) do update set role = excluded.role;

PUBLIC_SUPABASE_URL
PUBLIC_SUPABASE_PUBLISHABLE_KEY
veya PUBLIC_SUPABASE_ANON_KEY
