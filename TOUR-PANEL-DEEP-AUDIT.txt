CAPPADOCIAGO — TOUR PANEL / BRAND DEEP AUDIT
2026-08-30

Implemented
-----------
- /admin/tours: authenticated tour content management panel.
- Create, edit, delete, save draft and publish tour records.
- TR / EN / ES content tabs.
- Hero image upload + multi-image gallery upload to Supabase Storage.
- Current CappadociaGo detail-page content structure: overview, highlights,
  included, excluded, important info, itinerary, tour details, pickup,
  meeting point, price text, extra sections and SEO.
- Publishing syncs the live-booking products table (price/capacity/ask-for-price).
- New published tours render immediately through dynamic EN/TR/ES routes.
- Category pages append newly published database tours without requiring a redeploy.
- Dynamic pages reuse the same CappadociaGo StandardizedPrivateTourPage,
  SiteHeader, TourFooter, mobile behavior and booking UI as existing tours.
- Supabase Storage bucket: tour-images.
- API writes are protected by Supabase session + admin_users authorization.
- Legacy unauthenticated /api/add-tour endpoint now routes through the secured handler.

Brand cleanup
-------------
- Human-readable Turkey Balloons / Turkey Balloons Cappadocia references removed.
- WhatsApp assistant brandmark changed from TB to CG.
- Assistant copy remains CappadociaGo in EN/TR/ES.
- Internal legacy CSS class names that are not user-visible were not globally renamed,
  because doing so would risk breaking old tour templates.

Required Supabase step
----------------------
Run: supabase/cappadociago-tours.sql
The same tour-panel table additions are also mirrored in CAPPADOCIAGO-FULL-SETUP.sql.

Required environment variables
------------------------------
PUBLIC_SUPABASE_URL
PUBLIC_SUPABASE_ANON_KEY or PUBLIC_SUPABASE_PUBLISHABLE_KEY
SUPABASE_SERVICE_ROLE_KEY (server only)
