CAPPADOCIAGO - ADMIN PANEL KURULUMU

Supabase veritabanı ve admin kullanıcısı daha önce oluşturuldu.
Bu proje mevcut sitenin içine admin paneli entegre edilmiş halidir.

1) Proje ana klasöründe .env dosyası oluştur.
2) İçine şunları yaz:

PUBLIC_SUPABASE_URL=https://qeydouahyjzdvsithfyy.supabase.co
PUBLIC_SUPABASE_PUBLISHABLE_KEY=BURAYA_SUPABASE_API_KEYS_EKRANINDAKI_sb_publishable_ANAHTARI

Secret key KULLANMA.

3) Terminal:
npm install
npm run dev

4) Tarayıcı:
http://localhost:4321/admin

5) Supabase Authentication'da oluşturduğun admin e-posta/şifresiyle giriş yap.

Panelde:
- tüm ürünler
- aylık takvim
- günlük fiyat
- günlük kontenjan
- satılan / kalan
- müsait / dolu / kapalı
- tek gün düzenleme
- tarih aralığı toplu güncelleme
mevcuttur.

NOT: .env .gitignore içindedir. Secret key frontend'e eklenmemelidir.
